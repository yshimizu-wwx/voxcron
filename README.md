# Voxcron（ヴォクスクロン）

話して、そのまま入力。Windows 用の音声入力ソフトです。 by Wayfinder WorX

- `Win + 無変換`（スペースの左）を押して話すと、文字起こしと清書をして、カーソルの位置に入力します
- `Win + Shift + 無変換` で、選んだ文を声の指示で書き直します（「丁寧にして」「英語にして」など）
- 英語配列のキーボード（無変換キーがない）では `Win + Y` / `Win + Shift + Y` です。キーは設定で変えられます
- 単語帳・直した例・画面の言葉から、使う人の言葉づかいに合わせます
- 連続して話しても待たされません（変換中でも次を話せて、入力は話した順に入ります）
- 設定 → 単語帳の「履歴から単語帳を作る」で、これまでの入力から聞き間違いの候補を AI が探します。選んだものだけが単語帳に入ります

## インストール

1. [Voxcron のページ](https://wayfinderworx.com/voxcron?from=github) でメールアドレスを登録すると、インストーラー（`Voxcron-Setup-x.y.z.exe`）のダウンロードが始まります。ダウンロードしたファイルを実行してください
2. 「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」を押します（コード署名をしていないため）
3. 初回は設定画面が開きます。Groq の APIキー（無料）を作って貼り付けてください

管理者権限は不要です。新しい版は、しばらく使っていないときに自動で更新します（設定「更新」で「知らせるだけ」「確認しない」にもできます）。
