# Voxcron（ヴォクスクロン）

話して、そのまま入力。Windows 用の音声入力ソフトです。 by Wayfinder WorX

- `Win + J` を押して話すと、文字起こしと清書をして、カーソルの位置に入力します
- `Win + Shift + J` で、選んだ文を声の指示で書き直します（「丁寧にして」「英語にして」など）
- 単語帳・直した例・画面の言葉から、使う人の言葉づかいに合わせます

このリポジトリはインストーラーの配布用です（ソースコードは公開していません）。

## インストール

1. [最新のリリース](https://github.com/yshimizu-wwx/voxcron/releases/latest) から `Voxcron-Setup-x.y.z.exe` をダウンロードして実行します
2. 「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」を押します（コード署名をしていないため）
3. 初回は設定画面が開きます。Groq の APIキー（無料）を作って貼り付けてください

管理者権限は不要です。新しい版が出ると、タスクトレイのアイコンに「★ 新しい版に更新する」が出ます。

## ライセンス

はじめて起動した日から 14 日間は、すべての機能を試せます。その後はライセンスキーが必要です。
